## 📝 Описание
**Fisherman** — внешний бот для автоматической рыбалки в Albion Online на Python.
Поклёвка определяется по системному звуку (WASAPI loopback), мини-игра решается компьютерным зрением (OpenCV),
управление мышью идёт через WinAPI SendInput. Инжекта в клиент нет.

## ✨ Что нового в 3.0
- **Звук без Stereo Mix**: по умолчанию используется WASAPI loopback (звук системы, наушники тоже работают).
  Если loopback недоступен — автоматический откат на устройство ввода (Stereo Mix / VB-Audio Cable).
- **Адаптивный порог**: уровень сигнала сравнивается и с абсолютным порогом, и с шумовым фоном (`audio_ratio`).
  В GUI есть живой индикатор уровня, шумового фона и кнопка **Auto threshold**.
- **Наведение на зелёную зону**: поплавок удерживается в реальной зелёной зоне полосы (HSV-детект),
  а не в середине выбранного прямоугольника. Если зона не найдена — откат на центр, как раньше.
- **Контроллер с упреждением**: оценка скорости поплавка, упреждение 80 мс, гистерезис и deadband —
  меньше рывков ЛКМ, стабильнее удержание.
- **Быстрый и устойчивый поиск поплавка**: мультимасштабный шаблон (0.85/1.0/1.2) не зависит от масштаба UI,
  после захвата используется локальное окно ±80 px — хватает 100+ FPS на ROI.
- **Безопасность**: проверка фокуса окна Albion (в чужие окна не кликает), failsafe — курсор в левом верхнем
  углу останавливает бота, ЛКМ гарантированно отпускается при любом выходе из мини-игры.
- **Конфиг без eval**: `settings.ini` парсится через `ast.literal_eval`, старый формат поддерживается.
- **Диагностика**: `--selftest` (проверка CV, контроллера, захвата и аудио), `--headless`, лог в файл,
  превью зоны с отрисовкой детекта, debug-кадры мини-игры.
- **GUI**: статус, счётчики, индикатор уровня, хоткеи F8/F9, кнопки настройки как раньше.
- **Зависимости обновлены** под Python 3.10+ (DearPyGui 2.x, OpenCV, mss, soundcard, PyAudio).

## 🚀 Установка и запуск

### Требования
- Python 3.10+ (проверено на 3.11.9), Windows 10/11
- Albion Online в оконном режиме или «оконный без рамки»
- Установленный пакет зависимостей

### Шаги установки
```bash
git clone https://github.com/Renfild/fisherman.git
cd fisherman
pip install -r requirements.txt
python Fisherman.py
```

Проверка окружения без запуска бота:
```bash
python Fisherman.py --selftest
```
Self-test не двигает мышь: он проверяет шаблон, детект зелёной зоны, контроллер вываживания,
захват экрана и доступность аудио-бэкенда.

## 🔊 Звук

### Как есть по умолчанию
Бот слушает **системный звук** через WASAPI loopback (`soundcard`). Ничего настраивать не нужно:
достаточно, чтобы звук игры шёл в текущее устройство вывода (колонки/наушники).

### Если loopback не работает
Бот автоматически переключится на **устройство ввода** (PyAudio). Тогда:
1. Включите **Stereo Mix** (Realtek) или поставьте **VB-Audio Cable** устройством записи по умолчанию.
2. Перезапустите бота — в строке статуса будет `audio: input`.

### Рекомендуемые настройки звука в игре
| Источник | Значение |
|----------|----------|
| Общая громкость | 75% |
| Музыка | 0% |
| Атмосфера | 0% |
| Звуковые эффекты | 65–100% |

Если в статусе `level` не двигается при поклёвке — нажмите **Auto threshold** или подберите порог вручную
так, чтобы поклёвка уверенно превышала шумовой фон.

## 🎮 Настройки в игре
- Режим окна: оконный или оконный без рамки (в exclusive fullscreen захват может не работать).
- Разрешение любое; важно, чтобы **масштаб UI не менялся** между калибровкой и работой.
- Панель мини-игры должна быть видна целиком.
- Не двигайте камеру во время рыбалки: точка заброса привязана к экранным координатам.

## 🎮 Использование бота

### Интерфейс
```
LOAD / SAVE                 — загрузить/сохранить settings.ini
1. Add fishing spot         — точка заброса (навести + SPACE), можно несколько
2. Set tracking zone        — прямоугольник вокруг полосы мини-игры (два SPACE)
3. Setup bait               — слот наживки и кнопка USE (два SPACE), опционально
4. Set anti-fatigue point   — точка для шага персонажа раз в 5 минут, опционально
Clear spots                 — очистить список точек
Volume threshold            — абсолютный порог звука (0..32767)
Detection threshold         — порог совпадения шаблона поплавка (0.4–0.7)
Aim at green zone           — целиться в зелёную зону (рекомендуется)
hold pushes right/left      — в какую сторону ЛКМ двигает поплавок (по умолчанию right)
Require Albion focus        — не кликать, если окно Albion не в фокусе
Auto threshold              — порог = max(1200, шумовой фон × 3)
Test zone                   — окно превью: зелёная зона, поплавок, score (q — закрыть)
START (F8) / STOP (F9)      — старт/стоп
```

### Порядок действий
1. Зайдите в игру, возьмите удочку, встаньте у воды.
2. Добавьте 2–5 точек заброса (по воде, в радиусе заброса).
3. Выделите зону полосы мини-игры: от левого верхнего до правого нижнего угла, **плотно** вокруг полосы.
4. Нажмите **Test zone**, покликайте удочкой вручную и убедитесь, что зелёная рамка совпадает с зелёной
   зоной, а оранжевая — с поплавком.
5. Нажмите **Auto threshold**, затем **START**. Первые пару циклов наблюдайте.

## 🔧 Как работает бот

```
ЦИКЛ:
1. АВТОМАТИЗАЦИЯ  — еда (клавиша food_key раз в 30 мин), наживка (раз в 10 мин),
                     анти-усталость (ПКМ по точке раз в 5 мин)
2. ЗАБРОС         — случайная точка из списка + джиттер ±5 px, удержание ЛКМ 0.8–1.2 с
3. ОЖИДАНИЕ       — 3 с игнор звука после всплеска, затем ждём поклёвку до 22 с
4. ПОДСЕЧКА       — клик по точке заброса через ~0.4 с после звука поклёвки
5. ВЫВАЖИВАНИЕ    — поиск поплавка шаблоном, зелёной зоны по HSV, контроллер hold/release
6. ПАУЗА          — 1–1.8 с, повтор
```

### Ключевые системы
- **Детект поклёвки**: RMS-всплеск по высокочастотной огибающей; порог = `max(volume_threshold, floor × audio_ratio)`.
  Счётчик `serial` защищает от повторных срабатываний (cooldown 1.2 с).
- **Поплавок**: `TM_CCOEFF_NORMED` по шаблону `bobber.png`, три масштаба, локальное окно после захвата.
- **Зелёная зона**: HSV-маска, поиск самой длинной непрерывной колонки зелёного, центр зоны — цель.
- **Контроллер**: `hold`, если предсказанная позиция левее цели на deadband; `release`, если правее.
  Скорость поплавка оценивается по последним 180 мс, упреждение 80 мс.
- **Стейт-машина**: WAITING → HOOK → REEL → PAUSE, таймауты и восстановление после пропущенной поклёвки.
- **Фокус**: если Albion теряет фокус — бот останавливается (а не кликает в другое окно).
- **Failsafe**: курсор в левом верхнем углу (0..4 px) — немедленный стоп.

## ⚙️ settings.ini

Основные ключи (все читаются при старте, сохраняются кнопкой SAVE):

| Ключ | По умолчанию | Описание |
|------|--------------|----------|
| `coords` | `[]` | Точки заброса `[(x, y), ...]` |
| `screen_area` | `{...}` | Зона полосы мини-игры |
| `volume_threshold` | `3000` | Абсолютный порог звука |
| `audio_ratio` | `2.2` | Порог над шумовым фоном |
| `audio_source` | `auto` | `auto` / `loopback` / `input` |
| `ignore_after_cast` | `3.0` | Игнор звука после заброса, с |
| `hook_delay` | `0.4` | Задержка подсечки после звука, с |
| `detection_threshold` | `0.5` | Порог совпадения шаблона |
| `use_green_zone` | `True` | Целиться в зелёную зону |
| `hold_dir` | `right` | Куда ЛКМ двигает поплавок |
| `reel_deadband` | `6.0` | Мёртвая зона контроллера, px |
| `reel_lead` | `0.08` | Упреждение, с |
| `bite_timeout` | `22.0` | Ожидание поклёвки, с |
| `reel_timeout` | `16.0` | Максимум мини-игры, с |
| `food_key` | `2` | Клавиша еды |
| `food_interval` | `1800` | Интервал еды, с |
| `bait_interval` | `600` | Интервал наживки, с |
| `move_interval` | `300` | Интервал анти-усталости, с |
| `require_focus` | `True` | Требовать фокус Albion |
| `debug` | `False` | Сохранять кадры мини-игры в `debug/` |

## ⚠️ Устранение неполадок

| Проблема | Решение |
|----------|---------|
| Не реагирует на поклёвку | Проверьте `level` в статусе: при поклёвке он должен прыгать. Нажмите Auto threshold, проверьте звук игры |
| Ложные срабатывания | Увеличьте `volume_threshold`, уберите музыку/ютуб, увеличьте `audio_ratio` |
| `audio: -` в статусе | Нет ни loopback, ни устройства ввода. Проверьте `pip install soundcard pyaudio` |
| Не находит поплавок | Заново выделите зону, откройте Test zone: score должен быть > 0.5. Проверьте `bobber.png` |
| Поплавок найден, но дёргается | Уменьшите `detection_threshold` до 0.4–0.45, уберите лишние элементы UI из зоны |
| Не находит зелёную зону | Выключите «Aim at green zone» (будет центр зоны) или заново выделите зону плотнее |
| Мини-игра проигрывается | Переключите `hold pushes` на `left`, проверьте превью |
| Не стартует | Смотрите лог: нет точек заброса, зона не задана или выходит за экран |
| Клики уходят в другое окно | Оставьте «Require Albion focus» включённым |
| Бот остановился сам | Курсор был в левом верхнем углу (failsafe) или Albion потерял фокус |

## 🛠 Разработка

```bash
# Установка для разработки
git clone https://github.com/Renfild/fisherman.git
cd fisherman
pip install -r requirements.txt

# Диагностика без кликов мышью
python Fisherman.py --selftest

# Запуск без GUI (настройки из settings.ini)
python Fisherman.py --headless

# Отладка: кадры мини-игры сохраняются в debug/
# установите debug = True в settings.ini
```

### Структура проекта
```
fisherman/
├── Fisherman.py          # GUI, точка входа, превью зоны
├── core/
│   ├── audio.py          # WASAPI loopback / PyAudio + адаптивный порог
│   ├── bot.py            # стейт-машина, автоматизация, тайминги
│   ├── capture.py        # захват экрана (mss)
│   ├── config.py         # settings.ini без eval + валидация
│   ├── input.py          # SendInput, фокус окна, хоткеи, failsafe
│   ├── reel.py           # контроллер вываживания
│   ├── selftest.py       # диагностика
│   └── vision.py         # шаблон поплавка + зелёная зона
├── bobber.png            # шаблон поплавка
├── settings.ini          # конфигурация
└── requirements.txt
```

## ⚠️ Предупреждение

### Важная информация:
- **Это сторонний инструмент**, используйте на свой страх и риск
- **Может нарушать правила Albion Online** — уточняйте у разработчиков игры

- **Не используйте на важных аккаунтах** — возможны блокировки

- Используйте на отдельном аккаунте для рыбалки

- Уважайте игровую экономику и других игроков
